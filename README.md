# Hafees Ahamed — Personal Portfolio

A clean, professional portfolio website built with vanilla HTML, CSS, and JavaScript.

**Live:** [hafees14.github.io/My_Web_Portfolio](https://hafees14.github.io/My_Web_Portfolio/)

## Sections
- Hero — introduction with social links
- About — background and stats
- Experience — professional work history
- Skills — animated skill bars
- Projects — featured GitHub projects
- Volunteering — leadership and community work
- Contact — contact form and links

## Tech Stack
HTML5 · CSS3 · Vanilla JavaScript · Font Awesome · Google Fonts

## Deployment
Deployed via GitHub Pages from the `main` branch.
