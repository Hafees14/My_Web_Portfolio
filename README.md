## 📖 About
This website serves as a digital resume and project showcase. It was built from scratch to demonstrate front-end development skills and to provide a central hub for my work as a **Computer Engineering Undergraduate** at the University of Peradeniya.

It features details about my work in:
* **Systems Programming** (C, Assembly)
* **3D Graphics Engines** (libtiny3d)
* **Robotics & UAVs** (Arduino, Automation)

---

## ✨ Features
* **🎨 Modern UI/UX:** Clean, minimalist design with a focus on readability and professionalism.
* **📱 Fully Responsive:** Adapts seamlessly to mobile, tablet, and desktop screens using CSS Media Queries.
* **✨ Interactive Elements:**
    * **Smooth Scrolling** navigation.
    * **Typing Effect** on the hero section.
    * **Scroll Animations** (Fade-in effects) using `IntersectionObserver`.
* **📝 Contact Form:** A styled input form for inquiries.

---

## 🛠️ Tech Stack
This project uses pure, vanilla web technologies without heavy frameworks to ensure fast load times and full control over the code.

| Technology | Usage |
| :--- | :--- |
| **HTML5** | Semantic structure and layout. |
| **CSS3** | Custom styling, Flexbox/Grid layouts, and CSS Variables. |
| **JavaScript** | DOM manipulation, event listeners, and animations. |
| **Font Awesome** | Social media icons and UI elements. |
| **Google Fonts** | Typography (Poppins font family). |
